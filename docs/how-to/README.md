# How-to guides 🛠️

Goal-oriented recipes for real tasks. Each guide gets you from "I want X" to
"X is done" with nothing in the way. If you're learning the tool for the
first time, do the [tutorial](../tutorials/README.md) instead; for exact
facts, see the [reference](../reference/README.md).

- [Track repos and orgs](track-repos-and-orgs.md) — add, list, and remove
  tracked repos and whole GitHub orgs, including archived/fork inclusion and
  ignore lists
- [Schedule background syncs](schedule-background-sync.md) — the launchd
  agent vs. manual sync passes, and how to run both
- [Navigate checkouts with fish](navigate-checkouts-with-fish.md) — fuzzy
  repo navigation and tab completion in your shell
- [Migrate from the `src` identity](migrate-from-space-src.md) — you came
  from space-architect 8.x and your engine answered to `src`

Maintainer-facing release docs: none — repo-tender has no RELEASING.md.
Development setup lives in the [README](../../README.md#development-🧪).
