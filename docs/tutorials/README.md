# Tutorials 🎓

Learning-oriented, start-to-finish journeys. If you're new to repo-tender,
start here — each tutorial takes you from nothing to a working result, one
small verified step at a time.

- [Your first evergreen repo](first-evergreen-repo.md) — install, track a
  repo, sync it locally, check its health, and grab an instant copy. The
  whole loop in about five minutes.

When you want to *do* a specific task, head to the
[how-to guides](../how-to/README.md); for exact command and config details,
see the [reference](../reference/README.md).
